# Playbooks

How we do a recurring kind of task.

| Playbook | Use when | Status |
|---|---|---|
| [git-ship-a-change](git-ship-a-change.md) | Work is ready to commit, push and open as a PR; a branch needs updating | active |
| [desktop-app-setup](desktop-app-setup.md) | A new desktop app (Tauri 2, React, TypeScript) is needed | active (v1; checked by three fresh-session runs) |
| [app-bring-to-standard](app-bring-to-standard.md) | An existing app must conform to the standards that apply to it | active |
| [work-in-parallel](work-in-parallel.md) | The owner asks for an issue to be worked in parallel with another session | active |
| [plan-a-piece-of-work](plan-a-piece-of-work.md) | Larger work needs a plan before code; includes the reviewer's plan mode and the plan templates in the [templates index](../templates/INDEX.md) | active |
| [install-kit-existing-repo](install-kit-existing-repo.md) | The owner of an existing repo wants the kit installed: clash check, copy-in, memory PR | active |
| [adopt-existing-repo](adopt-existing-repo.md) | The kit is installed in an existing repo and the repo must now be brought under it, in stages (survey, sort, root guidance, baselines, gate) | active |
| [roll-out-a-standard](roll-out-a-standard.md) | An adopted repo needs one more standard while existing code is not yet in line: rank, inventory, write, baseline the check, file the migration | active |
| [contribute-upstream](contribute-upstream.md) | A project changed the framework tier (`memory-kit/`, `.claude/`, `.githooks/`, kit docs structure) and the owner agrees to submit it to the template | active |
| [take-in-upstream](take-in-upstream.md) | The owner asks to bring the template's newer changes into a project | active |
