# knowledge

Cross-project notes for the people using this repo. Open this folder as an Obsidian vault. Notes here never link to project files.

- `domains/<name>/`: portable notes, tracked. Add a folder when a domain is large enough, and a row in `INDEX.md` for each note.
- `personal/`: your own notes, untracked (see `.gitignore`).
- A note has front matter (`title`, `status`, `updated`) and links with relative markdown links, not wikilinks. The vault's Obsidian setting does this for new links.
